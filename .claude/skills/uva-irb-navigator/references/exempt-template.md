# Exempt Application Document Template

## Document Structure

The generated Exempt Application should follow this structure exactly, including only the appendices determined to be required.

---

## Header Block

```
EXEMPT APPLICATION

PI Name: [Full name]
Name of Person Submitting this form (contact): [Name]
Contact's Email: [email]

Is this study federally funded? [YES/NO]
If YES, complete Appendix J.

Does this study have support or sponsorship from outside UVA? [YES/NO]
If YES, complete Appendix J.

Will the study involve use of biospecimens? [YES/NO]
If YES, provide IBC#: [number if applicable]

Location of Data/Specimen Collection: [location]
```

## Screening Questions Section

**Answer each YES/NO based on study characteristics:**

### Block 1: Exempt Disqualifiers
All should be NO for exempt eligibility:
- Surveys or interviews given to minors
- Observation of public behavior in minors with investigator participation
- Procedures causing discomfort beyond daily life
- Deception without prospective agreement
- Research involving rare traits causing harm if disclosed
- FDA-regulated research
- Targeted enrollment of prisoners
- FERPA-governed data without consent
- Embryos, fetal tissue, stem cells
- New specimen collection for this research

### Block 2: Routing Questions
These determine which appendices to complete:
- Receiving data/specimens from outside? → Appendix A
- Sending data/specimens outside? → Appendix B  
- Recruitment involved? → Appendix F
- Recording involved? → Appendix I
- Compensation involved? → Appendix G
- HIPAA identifiers involved? → Appendix C, D
- Waiver of authorization needed? → Appendix E
