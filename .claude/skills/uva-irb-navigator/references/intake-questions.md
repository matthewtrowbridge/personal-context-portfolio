# IRB Intake Questions

## Instructions

Ask these questions in conversational order. Group related questions together. Don't overwhelm the researcher—start with basics and drill down as needed.

## Section 1: Study Basics

**1.1** What is the title of your study?

**1.2** In 2-3 sentences, what is the purpose of this research?

**1.3** Who is the Principal Investigator? (Name, department, email, phone)

**1.4** List any co-investigators with their names and departments.

## Section 2: Study Design

**2.1** What type of study is this?
- [ ] Secondary analysis of existing data
- [ ] Chart/medical record review
- [ ] Survey or questionnaire
- [ ] Interview study
- [ ] Observational study
- [ ] Specimen/biobank analysis
- [ ] Other: ___

**2.2** Briefly describe what will happen during this study (methods).

**2.3** Where will study activities take place?

## Section 3: Data Sources

**3.1** Where will data come from?
- [ ] Existing UVA database/records
- [ ] External database (specify source)
- [ ] New data collection from participants
- [ ] Combination

**3.2** If receiving data from outside UVA, specify the source organization and describe the data transfer arrangement.

**3.3** Will any data or results be shared outside UVA before publication?
- If YES: With whom? What data elements?

## Section 4: Identifiers and Privacy

**4.1** Will your study involve any of these HIPAA identifiers? (Check all that apply)
- [ ] Names
- [ ] Dates (birth, admission, discharge, death) except year
- [ ] Phone/fax numbers
- [ ] Email addresses
- [ ] Social Security numbers
- [ ] Medical record numbers
- [ ] Geographic data smaller than state (ZIP, address, county)
- [ ] Account numbers
- [ ] Health plan numbers
- [ ] Full-face photographs or comparable images
- [ ] Biometric identifiers
- [ ] IP addresses
- [ ] Device identifiers
- [ ] Vehicle identifiers
- [ ] Certificate/license numbers
- [ ] Web URLs
- [ ] Other unique identifying codes

**4.2** If identifiers ARE involved:
- Will you obtain signed HIPAA authorization from each subject?
- Will you need a waiver of HIPAA authorization? (i.e., impracticable to obtain consent)
- Is data provided as a Limited Data Set under a Data Use Agreement?
- Is data fully de-identified before you receive it?

**4.3** How will identifiable data be stored and protected?

**4.4** Who will have access to identifiable data?

**4.5** How long will identifiable data be retained?

## Section 5: Funding and Support

**5.1** How is this study funded?
- [ ] Federal grant (specify agency)
- [ ] Foundation grant (specify)
- [ ] Industry/commercial sponsor
- [ ] Departmental funds
- [ ] Unfunded

**5.2** Is there any contract or agreement with an outside entity?

**5.3** Will UVA receive any funding or in-kind support from outside organizations?

## Section 6: Subject Interaction

**6.1** Will you actively recruit participants?
- If YES: How? (flyers, emails, clinic approach, etc.)
- If YES: What recruitment materials will be used?

**6.2** Will participants receive any compensation, reimbursement, or gifts?
- If YES: What form and amount?
- If YES: Is payment prorated for partial completion?

**6.3** Will participants be recorded (audio, video, or photography)?
- If YES: How will consent for recording be obtained?
- If YES: How will recordings be stored and destroyed?

## Section 7: Special Populations

**7.1** Does your study specifically target any of these groups?
- [ ] Minors (under 18)
- [ ] Prisoners
- [ ] Pregnant women
- [ ] Cognitively impaired individuals
- [ ] UVA students
- [ ] UVA employees/residents/fellows

**7.2** If vulnerable populations are involved, describe protections in place.

## Section 8: Data Security (for Data Security Plan)

**8.1** How will data be COLLECTED?
- [ ] Paper forms
- [ ] Direct entry to UVA server
- [ ] Web-based survey/form (specify platform)
- [ ] Onto laptop/tablet/phone
- [ ] Other: ___

**8.2** How will data be STORED long-term?
- [ ] UVA Box
- [ ] UVA OneDrive
- [ ] REDCap
- [ ] Departmental server (specify)
- [ ] HIPAA-compliant server (specify name)
- [ ] Other: ___

**8.3** Will any identifiable data be stored on a personal device (laptop, phone)?

**8.4** Will data be transferred between systems? How?

## Section 9: Team and Experience

**9.1** Briefly describe the PI's relevant experience working with this type of data/population.

**9.2** Briefly describe co-investigators' relevant expertise.

**9.3** Have all team members completed CITI training?

## Quick Determination Questions

For rapid triage, these questions determine exempt eligibility:

| Question | Response |
|----------|----------|
| Does study involve minors in surveys/interviews? | YES = Not Exempt |
| Does study involve observation of minors with investigator participation? | YES = Not Exempt |
| Could the study cause discomfort beyond daily life? | YES = Not Exempt |
| Does study involve deception without prospective agreement? | YES = Not Exempt |
| Is this FDA-regulated research? | YES = Not Exempt |
| Does study specifically target prisoners? | YES = Not Exempt |
| Does study collect new biospecimens for this research? | YES = Not Exempt |
| Does study involve embryos, fetal tissue, or stem cells? | YES = Not Exempt |

If all answers are NO, study may qualify for Exempt review.
